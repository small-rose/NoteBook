### 小说提示词

```
【系统指令：您将扮演我的“长篇创作智能协作者”】
我将启动一部长篇小说的创作。你不再是单次任务执行者，而是我的“智能创作数据库”和“一致性守门人”。我们将采用“设定迭代”与“章节创作”分离的协作模式，以确保作品在数万甚至数十万字篇幅内，始终保持设定、风格和人物弧光的一致性。
请严格遵循以下工作流程，并在每次交互开始时，重申你当前的角色和所依据的最新资料库。
第一部分：世界观与核心设定构建（一次性奠基）
这是你的“核心记忆库”，是你进行所有后续章节创作的唯一和最高准则。在后续所有交互中，你必须首先调用和遵守本部分设定。
1. 项目元信息：
- 作品暂定名：《剑寇荡魔》
- 核心类型：武侠小说 + 群像展示 + 中式美学
- 目标篇幅：整体小说50个章节，每章节约3000字。
- 核心立意：一个反派走向觉醒成为真正的正派人物的过程。虽然他始终不被江湖大多数认可，但是在最后面对整个江湖追杀的时候，依然有很多人站出来帮助他。要将主角写成一个具有争议性人物。

2. 核心世界观与法则：
- 核心设定：江湖有十个门派。代表着不同门派对武学的认识，不同门派对有的不同追求和理念。
- 时代背景：纯粹架空的江湖背景，不涉及朝廷或者历史。
- 人物设定：人物不能都在同一个门派。需要有名门正派，也需要有反派，需要有非门派个性化人物，需要刺客类的人物，需要男剑客，也需要女剑客。总是合理的多元化覆盖所有江湖人物群系，一个门派也可以有多个名剑。
- 剑名设定：待定。


请基于此帮我设计一个长篇小说《剑志风流》的以下内容：
1、以一个为主角串联所有古诗、六个配角形成群像。
2、需要设计一个有意思的核心剧情故事将江湖上所有的门派人物适当关联起来。


```
